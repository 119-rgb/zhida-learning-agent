# 分阶段审查约定

每个业务模块及影响权限、状态、事务、工具边界的阶段完成后执行：

1. 对照当前需求、源码、数据库和接口检查实现，运行隔离自动测试。
2. 独立审查业务正确性、权限、事务/并发与测试有效性；注释检查其解释是否与实现一致。
3. 修复阻断/重要问题，对修复范围再审查并运行对应验证；非阻断边界明确记录。
4. 将范围、问题、修复、复查、实际测试与未执行验收写入本目录，更新项目状态后再进入下一模块。
5. 发布前另审查全部待发布历史和文件的隐私；业务审查通过不等于发布审查通过。
