# 模块 3 阶段审查记录

## 审查范围

独立只读审查公共产品售后知识库、私人知识库 owner 边界、上传/重试/删除权限、固定向量命名空间、研究 Agent 读取入口、检索证据、虚构演示资料、中文注释和自动测试。审查者未参与实现，也未修改工作区。

## 问题、修复与复查

首次审查发现 1 项 P1：公共逻辑 ID `product-support` 曾直接用作内部向量命名空间。旧本地模式允许同名私人命名空间，升级启用售后后可能把旧私人文档误当公共资料。

修复后，公共内部命名空间改为带系统域分隔的 SHA-256 值。其 64 位长度超过外部知识库 ID 的 50 位上限，旧外部 ID 无法构造；HTTP 响应继续映射为逻辑 ID。新增回归测试直接预置旧 `product-support` 目录项，确认公共 API 不会返回该文档。复查确认 P1 关闭。

审查另提出 2 项 P3，均已修复并再次复查：

| 问题 | 修复与复查 |
| --- | --- |
| 授权层会 trim ID，但响应曾回显原始路径值 | 新增统一 `logicalId()` 规范化，上传、列表、详情、重试和检索响应全部使用规范 ID；复查通过 |
| 管理员删除与公共内部 namespace 缺少直接断言 | HTTP 测试等待文档 READY 后验证管理员删除成功，并捕获索引分块确认 namespace 为 64 位且不等于逻辑 ID；复查通过 |

最终独立审查未发现未关闭的 P0–P3 问题。演示手册明确标记为虚构，没有真实身份、支付承诺或与实现不符的生产声明。
