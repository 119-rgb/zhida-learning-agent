## 保留边界

- 详情事务默认 REQUIRED，当前 HTTP 调用没有外层事务；未来嵌入其他事务时重新核查隔离保证。
- 角色重查拒绝已撤销角色，不保证撤权与正在进行的请求严格同步。
- 抢单失败可能返回 404 或 409，分别对应失去资源访问权或版本/数据库并发冲突。
- 自动测试为隔离 H2，真实 MySQL 及事务型存储引擎尚待独立验收；最多 100 条列表尚无分页。
- 索引初始化限单实例，已有同名索引不自动改写。

审查结论：工单核心及注释阶段通过独立静态审查；不将审查替代真实 MySQL、模型或浏览器验收。
