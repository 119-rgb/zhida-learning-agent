# 默认工具调用预算调整为 30

## 目标

把真实 Agent 单任务的默认工具调用上限从 8 次提高到 30 次。前 30 次调用允许执行，第 31 次调用触发 `TOOL_BUDGET_EXCEEDED`。保留 `ZHIDA_MAX_TOOL_CALLS` 环境变量覆盖能力和 1～50 的合法范围。

## 改动范围

- `ZhidaProperties.Execution` 的 Java 默认值改为 30。
- `application.yml` 和 `.env.example` 的默认/示例值改为 30。
- `ToolTracePublisher.open(taskId)` 的便利方法默认值改为 30，避免不同入口默认值不一致。
- README 同步说明默认预算和费用风险。
- 单元测试验证默认允许 30 次，并在第 31 次拒绝。

## 不改动

- 不改变单任务 90 秒总超时。
- 不改变每日任务额度、模型用量记录或费用告警。
- 不实现按问题动态预算，也不取消工具循环保护。

## 验证

先让默认预算边界测试在旧值 8 下失败，再修改实现使其通过，最后运行完整 Maven 测试和打包检查。
